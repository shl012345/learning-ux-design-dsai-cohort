# /examples

This folder holds **anchor artifacts** — real-world files that lessons reference and excerpt via the `real_world_excerpt` frontmatter field (see [`/CONTENT-SPEC.md`](../CONTENT-SPEC.md) §Optional `real_world_excerpt` field).

The idea: when a lesson explains a concept, it can point at a real file in here and show a syntax-highlighted excerpt in a sidebar, rather than retyping a toy example into the prose. The file in `/examples/` is the single source of truth; lessons reference it by path and line range.

## Conventions

- Keep one artifact per concern. Don't bundle.
- File names should be kebab-case and unambiguous (e.g. `figma-tokens-export.json`, not `example.json`).
- Comments at the top of each file explaining its provenance (where it came from, what version, what licence).
- If the artifact has a licence that allows redistribution, keep it in-repo. If not, document where to fetch it and reference a *local-only* copy with a `.gitignore` entry.

## When to add an artifact

When a single concept gets referenced from three or more lessons, it's a candidate. One-off examples are better written inline in the lesson prose.

## When this folder stays empty

It's fine for it to stay empty. The `real_world_excerpt` frontmatter field is optional — every lesson can omit it. The `RealWorldCallout` component still gets generated by Antigravity; it just goes unused until you add an artifact.
